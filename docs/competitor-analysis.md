# GIHA: Competitor Analysis

## Landscape Overview

The Media and Information Literacy (MIL) game/ed-tech space includes several notable projects. GIHA differentiates through its dual-mode structure (systems simulation + forensic investigation) and zero-infrastructure deployment.

---

## Direct Competitors

### Bad News / Get Bad News (DROG / Cambridge University, 2018)

| Aspect | Bad News | GIHA |
|--------|----------|------|
| **Format** | Single-player web game (1 mode) | Two-mode web game |
| **Gameplay** | You play as a disinformation creator spreading fake news | You play as an investigator defending a city |
| **Mechanics** | Social media feed simulation with tweet/image/content creation choices | ODE population simulation + forensic evidence board |
| **MIL skills** | Prebunking — understanding disinformation tactics | Hands-on investigation: spectrogram reading, metadata inspection |
| **Time** | ~15 minutes | ~15 minutes |
| **Cost** | Free | Free |
| **Platform** | Web | Web (static SPA) |

**GIHA edge:** Bad News teaches WHAT disinformation tactics look like. GIHA teaches HOW to investigate a specific piece of content. The two are complementary, but GIHA adds the population-level simulation that shows WHY disinformation spreads systemically.

### Go Viral! (WHO / UK Government, 2020)

| Aspect | Go Viral! | GIHA |
|--------|-----------|------|
| **Format** | Short browser game (1 mode) | Two-mode web game |
| **Gameplay** | Scroll through social media feed, rate content credibility | Manage city health + investigate cases forensically |
| **MIL skills** | Prebunking vaccination against common manipulation techniques | Tool-based verification + systems thinking |
| **Time** | ~5 minutes | ~15 minutes |

**GIHA edge:** Go Viral! is a quick inoculation exercise. GIHA is a deeper dive that teaches actual forensic tool usage.

### Troll Factory (YLE Finland, 2019)

| Aspect | Troll Factory | GIHA |
|--------|---------------|------|
| **Format** | Single-player web game | Two-mode web game |
| **Perspective** | Play as a disinformation creator | Play as a defense investigator |
| **MIL skills** | Understanding the tactics of Russian troll farms | Multi-modal analysis + evidence connection mapping |

**GIHA edge:** Ethically, GIHA puts the player on the DEFENSE side — not role-playing how to create disinfo, but learning how to detect and mitigate it.

### Factitious (American University Game Lab, 2017)

| Aspect | Factitious | GIHA |
|--------|------------|------|
| **Format** | Swipe-based mobile game | Desktop strategy + investigation game |
| **Gameplay** | Swipe left/right on news headlines to mark real/fake | Full simulation management + evidence board with connections |
| **MIL skills** | Quick news credibility assessment | Deep forensic verification + systems dynamics |

**GIHA edge:** Factitious teaches quick judgment on headlines. GIHA teaches the investigative process behind a case — examining evidence, applying tools, connecting clues.

---

## Indirect Competitors

| Tool | Category | GIHA's Differentiation |
|:-----|:---------|:-----------------------|
| Snopes / PolitiFact | Fact-checking websites | Reactive (debunks exist AFTER disinfo spreads). GIHA is proactive — teaches the player to investigate independently |
| MIL curriculum textbooks (e.g., UNESCO MIL Curriculum) | Classroom materials | Passive learning. GIHA is interactive — the player learns by doing, with real-time feedback on their decisions |
| Reverse image search (Google Images, TinEye) | Specialized tools | Each tool is a standalone utility. GIHA integrates 6 tools into a single investigation workflow with case context |
| Deepfake detection platforms (e.g., Sensity AI) | Enterprise tools | Require technical expertise. GIHA makes the detection process accessible to anyone with a browser |

---

## Market Position

GIHA occupies a unique space: **proactive, systems-level MIL education delivered through hands-on investigation**. No other tool combines:

1. A real-time population simulation with ODE dynamics that teaches WHY disinformation spreads
2. A forensic investigation mode with 6 domain-specific tools that teaches HOW to verify content
3. A feedback loop where the quality of your investigation directly affects the simulation
4. Zero-cost, zero-install deployment that works on any modern desktop browser
