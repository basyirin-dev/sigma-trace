# Phase 11: Proposal & Pitch Video

**Duration:** 4 days
**Members:** M1+M2
**Dependencies:** Phase 10 (playtesting — need game footage)
**Output:** Completed UNESCO proposal document + 180-second pitch video

## Tasks

### 11.1 Finalize Proposal Text (M1)
- Using 05-proposal-outline.md as template:
  - Fill all 8 sections with final content
  - Include specific game mechanics references (R₀, σ-coherence, 6 tools)
  - Connect each feature to an MIL competency
  - Add citations: Σ-Model paper (if published by now), UNESCO MIL frameworks
  - Target: 2,500–3,500 words
- **Output:** `sigma-trace-unesco-proposal.pdf` (exported from Markdown via Pandoc)

### 11.2 Design Proposal Layout (M2)
- Create cover page with GIHA logo + UNESCO branding (use official assets)
- Typography: consistent with game's design system
- Include screenshots from game (record during playtesting)
- Charts/diagrams: strategy-detective loop flowchart, R₀ simulation graph
- Export: letter size, print-ready PDF
- **Output:** Final proposal PDF

### 11.3 Storyboard Pitch Video (M1)
- Using 04-pitch-script.md:
  - Time each section with actual game footage timing
  - Mark exact demo moments: city simulation, intervention deploy, evidence board, tool use, verdict, game over/victory
  - Adjust script if footage timing doesn't match
- **Output:** Annotated storyboard

### 11.4 Record Voiceover (M1)
- Use decent microphone or rent studio time if budget permits
- Read 04-pitch-script.md at steady pace (target: 180s ± 5s)
- Record 3 takes → pick best
  - Take 1: natural read
  - Take 2: slightly slower with dramatic pauses
  - Take 3: energetic, faster pace
- Post-processing: noise reduction, normalize volume, remove breath noises
- **Output:** `pitch-voiceover.wav` (48kHz, 16-bit)

### 11.5 Record Gameplay Footage (M2)
- Use OBS Studio or similar:
  - Record at 1920×1080, 30fps
  - Capture: title screen → strategy (30s) → Case 1 (30s highlights) → tools (20s) → victory (10s)
  - Total: ~90s of gameplay footage
  - Keep cursor visible, show intentional player decisions
- **Output:** `gameplay-footage.mp4` (raw, no audio)

### 11.6 Edit Pitch Video (M1+M2)
- **M2:** Video editing (DaVinci Resolve or CapCut):
  - Combine: gameplay footage + voiceover + text overlays
  - Add transitions: smooth crossfade between sections
  - Add lower-thirds: tool names, R₀ values, σ-coherence scores
  - Add call-to-action slide: "Help us build an informed society"
  - Background music: use game's title music (30s loop, auto-duck during voiceover)
- **M1:** Sync voiceover timing with footage
- **Output:** `pitch-video-final.mp4`

### 11.7 Closed Captions (M1)
- Generate SRT file for pitch video
- Manually verify sync at 3 points (beginning, middle, end)
- Include in submission package
- **Output:** `pitch-video-captions.srt`

### 11.8 Accessibility for Video
- Ensure sufficient contrast in text overlays
- No flashing/strobing content (check with photosensitive epilepsy checker)
- Captions available
- Audio description track if possible
- **Output:** Accessibility checklist completed

## Acceptance Criteria
- [ ] Proposal PDF complete, designed, with screenshots and diagrams
- [ ] Pitch video exactly 180s (±3s)
- [ ] Voiceover clear, well-paced, professionally recorded
- [ ] Gameplay footage shows all key features
- [ ] Video includes lower-thirds, transitions, call-to-action
- [ ] Closed captions available (SRT)
- [ ] Accessibility requirements met
- [ ] All assets ready for submission
